# 관통 프로젝트 5회차 - 도서

프로젝트 구성
- books app
  - 4회차 관통 프로젝트에서의 기능과 같은 구성.
  - 내용을 복습하는 차원에서 레이아웃 외의 요소는 다시 작성하였다.

- accounts app
  - 이번 주차 django 강의에 해당하는 내용.
  - 프레임워크가 제공하는 authentication system이 기본적으로 탄탄한 편이고 강의 내용과 거의 동일하였기에 기능을 구성하는데 큰 어려움이 없었다. 도전과제 관련 내용도 시도해보고 싶었으나, 평소보다 시간이 다소 부족한 관계로 구성하지 못했다.
